# Project Notes

## Dataset

The project uses the Cisco Networking Academy Movies dataset containing 4,535 films released between 2000 and 2017.

## Data Cleaning

The Excel analysis retained 3,420 films after removing records with missing budget or revenue values.

## Calculated Metrics

- Profit
- ROI
- Profit Margin
- Budget Category

## SQL Analysis

The project contains 10 main SQL queries and one bonus comparison query.

The analysis covers:

- Dataset overview
- Highest-grossing films
- ROI
- Annual revenue trends
- Language performance
- Budget tiers
- Critical and commercial success
- Popularity
- Runtime
- Profit by year
- English vs non-English films

## SQL Compatibility

The SQL file is primarily MySQL-compatible.

The SQL file also documents SQLite alternatives for functions such as YEAR() and FORMAT().
